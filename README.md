# SaaS Landing Page — Nexulo (fictional)

A modern, responsive landing page for a fictional AI automation startup called **Nexulo**. It is a front-end design demo — Nexulo is not a real company and nothing on the page is a real offer.

## What It Does

The page includes these sections:

- Sticky navigation bar
- Hero section with headline, call-to-action buttons and a mock "product window" (built with plain HTML/CSS — no screenshots or external images)
- Features grid (6 cards)
- "How it works" (3 steps)
- Pricing (3 plans, one highlighted)
- FAQ with expandable answers (HTML `<details>`)
- Call-to-action banner and footer

Everything is original text written for this demo. No copied logos or brand assets are used.

## Tech Stack

- HTML5 (one file, `index.html`)
- Tailwind CSS via CDN
- Google Fonts: Sora and Inter
- No JavaScript framework, no build step

## How to Run

No installation needed:

1. Download or clone this repository.
2. Open `index.html` in any modern browser.

Or serve it locally (optional):

```bash
python -m http.server 8000
# then open http://localhost:8000
```
