FAQ

Questions, answered

Do I need to know how to code?

No. You describe workflows in plain language, and the agent builds the steps. If you can write a message to a colleague, you can use Nexulo.

What happens if the agent makes a mistake?

It pauses and asks you. Every run is logged step by step, so you can review what happened and adjust the workflow in one click.

Can I try it without a credit card?

Yes. The Starter plan is free with no card required, and paid trials last 14 days.

Is Nexulo a real company?

No — Nexulo is fictional. This page is a front-end design demo built with plain HTML and Tailwind CSS.
